1. **MCP Overview**
   - Projects:
     - MCP Specification
     - MCP SDKs
     - MCP Development Tools
     - MCP Reference Server Implementations

2. **MCP Participants**
   - **MCP Host**: Coordinates and manages MCP clients.
   - **MCP Client**: Connects to MCP Server and obtains context.
   - **MCP Server**: Provides context data to MCP clients.
   
   Visual Example:
   
   ```
   [MCP Host]
       |
   [MCP Client] ------> [MCP Server]
   ```

3. **MCP Layers**
   - **Data Layer**
     - Lifecycle management
     - Server features
     - Client features
     - Utility features
   - **Transport Layer**
     - Connection establishment
     - Message framing
     - Authorization

4. **Conceptual Layer Structure**

   ```
   +-------------------+
   |   Transport Layer |
   +-------------------+
   |     Data Layer    |
   +-------------------+
   ```
